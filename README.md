# BOB Subastas - Agente IA (Hackatón SomosBOB 2025)

Proyecto para construir un agente conversacional con RAG para BOB Subastas.

## Estructura

- backend/: API en FastAPI + lógica de RAG + SQLite
- frontend/: interfaz web de demo en Streamlit
- data/: fuentes de conocimiento y base vectorial (Chroma)
- scripts/: scripts de ingestión de conocimiento

## Cómo empezar

1. Crear entorno virtual
2. Instalar dependencias
3. Levantar backend con uvicorn
4. Levantar frontend con streamlit
